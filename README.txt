## Reseller API SDK

Reseller API SDK - a library for interacting with the Reseller REST API which provides a convenient and easy interface.
Using this library you will get the following features:

* call all the Reseller REST API methods;
* manipulate with data with use of objects instead of array;
* autocompletion for objects for all the entities in the IDE (domains, customers, etc);
* exception-based handling of errors;
* logging of requests, etc.

To use the SDK, you need to get the Reseller API Key, that can be found in your Reseller Console.

#### Documentation
